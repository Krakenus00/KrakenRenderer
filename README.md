# KrakenRenderer

**WIP**  
A rendering engine with different rendering libraries or sth.

Started as an experimental project. Ended up being my playground.
Feel free to look around and copy the code you like.
For anything substantial, please mention me as the original creator.

Maybe at some point it will become something useful, who knows

# Supported Systems

I'm targeting the following systems:
* Windows 11
* (WIP) macOS 26
* (WIP) Arch btw

It may or may not work on other systems/versions. I won't test it

# Runtime Requirements

Only Vulkan, if you want to use it. Linux users have no choice btw.

# Build Requirements

### Windows

* Visual Studio 2022
* WinUI 3
* DirectX 12 compatible GPU
* Vulkan SDK

### macOS

* XCode 26
* Vulkan SDK

### Linux

* GCC 12
* CMake 4
* Ninja
* Kirigami UI
* Vulkan SDK
